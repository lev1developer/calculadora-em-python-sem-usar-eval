# 🧮 Calculadora em Python sem `eval()`

Uma calculadora simples desenvolvida em Python para praticar lógica de programação, funções, estruturas condicionais e operações matemáticas, sem utilizar a função `eval()`.

## 📌 Sobre o projeto

Este projeto foi desenvolvido como parte dos meus estudos em Python, com o objetivo de praticar os fundamentos da linguagem por meio da criação de uma calculadora executada pelo terminal.

A calculadora recebe dois números, solicita uma operação matemática e exibe o resultado.

## ⚙️ Funcionalidades

- ➕ Adição
- ➖ Subtração
- ✖️ Multiplicação
- ➗ Divisão
- 🚫 Verificação de divisão por zero
- 🔢 Suporte a números decimais utilizando `float()`
- 🧠 Seleção de operações com estruturas condicionais (`if` e `elif`)
- 🛠️ Implementação sem utilizar `eval()`

## 🛠️ Tecnologias utilizadas

- **Python 3**
- **Git e GitHub** para versionamento e compartilhamento do código

## 🚀 Como executar

### Pré-requisitos

Ter o Python 3 instalado no computador.

### Passo a passo

1. Clone o repositório:

   ```bash
   git clone https://github.com/lev1developer/calculadora-em-python-sem-usar-eval.git
   ```

2. Entre na pasta do projeto:

   ```bash
   cd calculadora-em-python-sem-usar-eval
   ```

3. Execute o programa:

   ```bash
   python calculadora.py
   ```

## 💻 Exemplo de uso

```text
digite seu numero: 10
digite o segundo: 5
digite soma + - / * : +
resultado 15.0
```
